# Ampactor Labs

**Software that proves what it does, and what it cannot do.**

Ampactor Labs is a one-person lab in Salt Lake City building programming
languages, audio systems, and verification infrastructure, all held to the
same standard: claims stated plainly, answered with evidence, and reproducible.

## Flagships

**[Mentl](https://github.com/ampactor-labs/mentl)**
a self-hosting programming language where a program's
effects, reach, and memory footprint are part of the syntax,
checked by the compiler, and answerable through `why`.
Run it in the browser: [mentl.ampactor.dev](https://mentl.ampactor.dev)

**[Sonido](https://github.com/ampactor-labs/sonido)**
36 audio effects written once in Rust, running in three places:
a bundle of DAW plugins, a browser node-graph editor,
and firmware on an Electrosmith Daisy Seed.

**[Forge](https://github.com/ampactor-labs/forge)**
a Rust-native agent harness: multi-provider tool loops, 
agent spawn and ring coordination, and a capability-based guard
that decides what an agent may touch before it acts.
